# ひらがな麻雀 (スマホWebアプリ)

「ひらがじゃん 牌ばーじょん」(https://youtu.be/1YdwN1sekdU) 風のファンメイド・ひらがな麻雀。
ひらがなの牌でことばを作って上がる。スマホ縦持ち推奨。

- ルール・設計 → [SPEC.md](SPEC.md)
- オンライン対戦の内部仕様 → [docs/SERVER_SPEC.md](docs/SERVER_SPEC.md)
- 常時公開の手順 → [DEPLOY.md](DEPLOY.md)

## 遊びかた
手牌13枚 + ツモ/ロンの1枚 = 14枚を「**2文字のことば×1 + 3文字のことば×4**」に分けられたら上がり。
ポン(捨て牌+手牌2枚で3文字語)・カン(手牌だけで4文字語)・ロンあり。
得点は 8点 + レア牌×2点 + カン×2点。

## 動かしかた

**この2つだけが正式な起動方法。** どちらもリポジトリ直下で実行する。

### 1. ローカルで遊ぶ / 開発する
```bash
npm install
npm start
```
→ http://localhost:8737 。全モードが動く。

### 2. インターネットに一時公開する (Windows)
`オンライン公開.bat` をダブルクリック。ゲームサーバとCloudflare Quick Tunnelが起動し、
公開URL (`https://○○.trycloudflare.com`) が表示され、クリップボードにコピーされる。

> **このURLは毎回変わり、PCの電源が入っている間だけ有効。**
> 最新のURLは `tools/public-url.txt` に保存される。
> 固定URLで24時間公開したい場合は [DEPLOY.md](DEPLOY.md)。

### モード別の必要環境
| モード | サーバ | 内容 |
|---|---|---|
| フリー対戦 | 不要 | CPUと対戦。人数2〜4・つよさ3段階・局数を選べる |
| ことば図鑑 / 実績 / ショップ | 不要 | 収集要素。記録はブラウザに保存 |
| **ランク戦** | **必要** | オンラインマッチング。4人集まるか10秒でCPUが補充。順位でRP増減 (G→S) |
| **ともだち対戦** | **必要** | 4文字のルームコードで合流。2〜4人+CPU |

`dist/hiragana-mahjong.html` は単一ファイル版 (ダブルクリックで開ける)。
**通信しないため、ランク戦とともだち対戦は使えない**(ボタンが自動的に隠れる/案内が出る)。

## モードとやり込み要素
- **ランク戦**: G→F→E→D→C→B→A→S。1位+30 / 2位+10 / 3位-10 / 4位-25 RP、100RPで昇格。
  ランクが上がるほどCPUの語彙率が上がる (G=20% 〜 S=100%)。
- **ことば図鑑**: 自分が作ったことば(上がりの5語+自分のポン/カン)を記録。全2396語。新語1つ 🪙+3。
- **実績・称号**: 20種類。解除でコイン、最新の称号がタイトルに出る。
- **シェア画像**: 上がった局をCanvasで画像化。共有シート or 長押し保存。

## コイン・ショップ・広告 (すべてデモ経済。実際の課金は発生しない)
- コイン入手: 対局報酬 (1位40/2位25/3位10/4位5)、新語発見、実績解除、リワード広告 (+30・1日5回)
- コインで買える物: 牌テーマ3種・卓テーマ2種 (各🪙300)、ヒント券×5 (🪙100、フリー対戦限定)
- **課金専用**: 広告なし (デモ¥480)。コインでは買えない
- 広告: 起動時 + 対局2回に1回のデモ広告 (3秒でスキップ可)
- ランク戦・オンラインの有利不利を買える物は無い (Pay-to-Win を入れない方針)
- 実決済・実広告への差し替え箇所は `src/economy.js` の `buyCoinPack()` / `buyAdFree()` と
  `src/ui.js` の `showAdModal()`

## 辞書 (2026-08-15から全網羅方式)
**16,788語** (2文字1,233 / 3文字5,792 / 4文字9,763)。
手持ちの語彙リスト全部に加え、**JMdict** の常用語 (優先度マーカー付き) を取り込んでいる。
CPUの強さは「知っている語の数」(やさしい700語〜むずかしい2,400語) で固定しているため、
辞書が大きくなっても相手の強さは変わらない。バランス実測値と設計上のトレードオフは
[SPEC.md](SPEC.md) の「辞書仕様」を参照。

> 本辞書の一部は EDRDG の [JMdict](https://www.edrdg.org/jmdict/j_jmdict.html) を元にしている
> (ライセンス: CC BY-SA)。抽出スクリプトは `tools/import_jmdict.mjs`。
